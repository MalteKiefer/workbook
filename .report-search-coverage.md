# Report: search-coverage

## Status: DONE

## Summary

`search_directory` in `src-tauri/src/db/search.rs` now also matches `customers.notes` and `systems.notes`, in addition to the fields it already matched (`customers.name`/`short_code`, `systems.name`/`hostname`/linked `external_refs.payload_json`). An admin who wrote identifying text only in a customer's or system's Notes field can now find it via the Command Palette's live directory search. The change is a pure SQL addition: one `OR notes LIKE ?1 COLLATE NOCASE` clause inside each existing parenthesized `WHERE` group, so the `archived_at_utc IS NULL AND (...)` guard still applies to the widened OR-group exactly as it did before. Nothing about the function's signature, parameter binding, or result shape (`DirectoryHit`) changed, so no frontend changes were needed.

Three new tests were added to the existing `#[cfg(test)] mod tests` block in the same file, following the file's established pattern of adding narrowly-scoped extra rows/updates inside the test body rather than modifying the shared `seed()` helper.
